# OSSPolicyGuard Tracking

This repository uses two tracking mechanisms:

1. `requirements_status.csv` for a machine-readable implementation status list.
2. GitHub issues and project tracking for public progress and review.

## How to use

- Update `requirements_status.csv` whenever a requirement moves from `Pending` to `In Progress` or `Done`.
- Create a GitHub issue for any requirement that needs external review or a follow-up task.
- Link issues from the CSV `notes` field when a requirement has an associated issue or PR.
